Fase 1 · Verificar ISOs, apagar Wi-Fi y crear los 5 Linux Bridges

Próximo paso en vivo

Conviene tener la pantalla de la ThinkPad a mano 5 minutos mientras se migra enp3s0f0 a br-wan por si cambia brevemente el enlace. (Pasos 5 y 6)

# 1. Verificar descargas completas de la noche:
cat ~/tp-infra/isos/download.log | tail -n 20 && ls -lh ~/tp-infra/isos/

# 2. Apagar Wi-Fi para no duplicar ruta a 192.168.1.0/24:
nmcli radio wifi off

# 3. Migrar enp3s0f0 -> br-wan (con MAC clonada para conservar 192.168.1.111) + 4 bridges L2 sin IP:
NIC="enp3s0f0"
NIC_MAC="$(cat /sys/class/net/$NIC/address)"
nmcli con add type bridge ifname br-wan con-name perfil-br-wan ethernet.cloned-mac-address "$NIC_MAC" bridge.stp no
nmcli con add type bridge-slave ifname "$NIC" master br-wan con-name esclavo-wan
nmcli con down "Wired connection 1" && nmcli con up perfil-br-wan && nmcli con up esclavo-wan

for br in br-users br-admin br-portfw br-ruteada; do
  nmcli con add type bridge ifname "$br" con-name "perfil-$br" bridge.stp no ipv4.method disabled ipv6.method ignore
  nmcli con up "perfil-$br"
done
ip -br a && bridge link
